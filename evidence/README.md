# Sanitized research evidence

This folder holds reviewed material supporting the original **HP L70** research, not raw machine images.

Good examples: firmware **public-package** metadata/checksums, short sanitized disassembly references, synthetic validation results and coarse aggregate outcomes.

Never include actual BIOS/SPI/NVRAM dumps, proprietary binaries, credential digests, recovered passwords or key sequences, raw candidate data, restore/pot files, serials, UUIDs or unreviewed logs.

The current Panasonic CF-54 research notes are in [its platform directory](../platforms/panasonic/toughbook-cf54/README.md); no private Toughbook artifact has been uploaded.
