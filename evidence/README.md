# Sanitized evidence

This directory is for small, reviewed artifacts that support the technical write-up without redistributing firmware or exposing machine-specific secrets.

Good candidates include:

- sanitized firmware/package metadata;
- checksums of official HP update packages;
- relevant function/offset maps;
- short, reviewed disassembly excerpts;
- synthetic validation output;
- aggregate cracking benchmarks.

Do not place raw firmware, SPI dumps, real hashes/passwords, serial numbers, UUIDs, or unreviewed terminal logs here.
